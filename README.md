# 小说写作工作台

本地优先的中文小说工具，工作区提供 **正文、大纲、当前状态速查、书籍资料库、LLM 配置**。书架用于选择、创建和管理小说，每本书的内容独立保存。

后续长篇连载流程见 [开发规划](PLAN.md)，包含用户提供的工作流原文、分阶段功能及第一步验收要求。规划中的功能不代表已经实现。

## 当前功能

- 正文：章节创建、编辑、删除、排序，TXT/Markdown 拆章预览与导入，阅读与专注模式，阅读位置、字号、版本历史、差异比较、恢复及 TXT 导出。正文和历史内容按需读取。
- 梗概：正文页支持手动生成本章梗概及批量更新。批量跳过空章和正文未变化的已有梗概；仅发送本书对应章节的已保存正文。生成失败保留旧梗概，生成途中正文更新则拒绝写入旧结果。
- 大纲：每本小说只有一份当前大纲，直接编辑完整文本，不再分卷、阶段或大纲块。每次保存生成不可覆盖的历史版本；可以查看旧稿或恢复为新版本。
- 当前状态速查：独立页面，显式调用当前启用 LLM，完整发送本书最新已保存大纲全文、按章节顺序排列的最后 5 章正文及全部已有章节梗概。生成 Markdown 并保存历史，支持手动编辑、恢复和来源过时提示；页面设置可修改本书提示词。JSON 与 Markdown 提取接口见 [接口文档](docs/current-state-api.md)。
- LLM 配置：全局管理 OpenAI Compatible 接口、密钥、模型参数和连接测试，支持读取模型列表、删除配置和清除密钥。启用一个配置会停用其他配置；停用模型不会被自动选中。保存正文、大纲或配置均不会自动调用模型。
- 书籍资料库：本书独立的写作规则和普通资料，标题与正文共同保存历史；支持模板填写、原始 / Markdown 单栏切换、SVG 复制、历史恢复及并发保存保护。接口见 [资料库接口文档](docs/materials-api.md)。本阶段由作者维护，尚不自动加入 LLM 请求。
- 备份：工作区右上角可下载当前书籍备份，在书架预览并恢复为独立副本。包含正文、大纲、状态速查、书籍资料全部历史及本书速查提示词、梗概、书籍信息、章节顺序和阅读位置；不包含模型密钥、旧功能数据或浏览器未保存草稿。备份版本 3 兼容版本 1、2 导入。

## 保存与任务

书架与工作区右上角提供全局「原始 / Markdown」切换，并记住选择。正文、大纲、梗概、书籍简介、版本备注、历史预览与导入预览使用同一显示格式。原始模式显示可编辑文本，Markdown 模式在同一单栏内显示排版内容，不同时展示原文和预览，切换保留未保存草稿；版本比较显示两份排版后的内容，原始模式保留字符差异标记。支持标题、强调、列表、任务列表、表格、引用、代码块、链接及图片；内嵌 HTML 按文本展示，不执行脚本。

所有文本输入框及内容展示区都有 SVG 复制按钮，复制原文而非渲染后的 HTML，成功或失败会提供反馈。密码框只复制当前输入值，不读取已保存密钥。显示切换、复制均不创建版本；保存、备份及 TXT 导出保留原始 Markdown 文本。

正文与标题一起提交，新正文版本直接存入 SQLite 事务。多窗口编辑会检查来源版本；冲突时保留当前草稿。浏览器会保存未提交的正文草稿，刷新后自动恢复；浏览器存储不能替代正式保存与书籍备份。

原有正文文件继续兼容读取，文件缺失或无法读取时明确报错。批量导入先预览，确认后整个批次在同一个事务中创建，失败不会留下半本书。支持 UTF-8、GB18030 及带 BOM 的 UTF-16；单文件上限 30 MB。

批量梗概以持久化任务运行，逐章保存结果。刷新或离开页面不影响执行，同一本书不会同时启动两个批量任务。可以查看逐章进度、停止和重试失败或未完成章节；停止在当前章结束后生效。服务重启后，未完成任务等待手动继续，不会自动调用模型。任务保存启动时的模型参数；继续任务时使用当前启用配置。请使用项目启动器的单个后端实例。

恢复书籍备份会校验文件格式和版本引用，再一次性创建副本；不覆盖原书。界面恢复上限 200 MB。

已移除角色卡、知识库、事件轴、图谱、分析记录、提示词组合及自动分析/入库的页面、接口和执行代码。

## 字体与排版

采用 WN 的 Noto Sans SC / Noto Serif SC 字体，使用 Fontsource 可变字体包本地加载，运行时不请求 Google Fonts。正文与大纲默认 18px、2.05 倍行高、0.03em 字距；阅读字号仍可调整。字体授权文件随构建保存在 `font-licenses/`。

## 旧数据兼容

启动后会将每本书现存的旧大纲按更新时间转换为全文历史；原大纲标题、描述和分段内容（包括目标、冲突、转折、结尾与章节范围）均保留在文本中。最近更新的大纲成为当前稿，其余可在历史中查看。转换可重复执行，不会重复生成版本或覆盖后续编辑。

旧系统未保存的修改过程无法补回。旧分段记录与已移除功能的数据库表保留作为历史数据，不再提供操作接口，也不会自动处理。转换只添加全文版本，不删除原始数据。

同一份大纲在多个窗口编辑时，过时的保存会被拒绝，编辑内容留在当前窗口，避免覆盖新稿。

## 启动

首次安装依赖：

```powershell
python -m pip install -r backend/requirements.txt
cd frontend
npm install
```

在项目根目录执行：

```powershell
python run.py
```

- 前端：http://localhost:5173
- 后端文档：http://localhost:8000/docs

启动器只管理本项目的前后端，服务已启动时不会重复创建进程。更新代码后，如旧服务仍在运行，请通过启动器停止并重新启动，以加载新的后端接口及大纲转换。

## 验证

后端测试使用每次新建的临时数据库和内容目录，结束后清理，不访问实际小说数据：

```powershell
cd backend
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
python -m pytest -q
```

前端构建与浏览器测试：

```powershell
cd frontend
npm run build
npm run test:e2e
```

浏览器测试自动启动独立前后端，使用 `test_data/playwright/run-*/` 下的独立数据库。

## 数据位置

- 本机数据库：`data/noveltools.db`（包含新正文版本、大纲全文历史、梗概任务及 LLM 配置）。
- 旧正文版本：`data/books/<book_id>/chapters/<chapter_id>/v<version>.txt`，仍需保留。
- 服务日志：`data/logs/`。

数据库、小说正文、密钥、缓存和测试产物均已被 Git 忽略。备份时应同时复制数据库与正文版本目录；Git 提交只备份代码。

## 回滚代码

本轮工作按独立步骤提交，见 `WORK_LOG.md`。Git 回滚不会撤回小说内容。

回到 `ef20f12` 之前的代码时，旧程序不认识数据库中的新正文存储字段。请先导出需要保留的书籍备份，并在停止服务后同时恢复该代码时期的数据库和正文目录；直接回退代码可能无法读取后来保存的正文。完整本机备份还应包含 `.env`，其中有敏感配置，请妥善保管。

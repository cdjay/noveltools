# 《宗门不传的功法，我传》章纲1—20与大纲对照审查

审查日期：2026-09-10。书籍ID：5。

结论：**宏观路线没有改道，但章纲尚未完全对齐。已有勘误没有全部落实到单章内容；主角动机、成长和赵平转向存在承接缺口；传功影响外部矿工的核心剧情启动偏迟。无需全盘重写大纲，应优先修正章纲。**

**用户补充原始定位后的判断更新：**上面的“宏观路线没有改道”只指章纲相对当前大纲。若对照最初“GitHub修仙、功法共建”的创意，当前大纲本身已出现核心重心偏移。固定规则仍保留合作与公开，但四卷主要事件缺少由他人贡献、共同验证、改良合流驱动的因果链。因此，后续工作应先明确大纲的共建主线，再调整章纲，不能仅加快当前逃生与对抗剧情。以下追加分析不构成大纲修改。

本次为只读审查，没有修改小说、大纲、章纲、梗概或状态速查，没有调用生成模型。此报告评价的是计划，不据此断言现有正文也有同样问题。

## 三、明确冲突：原章纲仍保留的旧问题

这些多数已在共同勘误中被指出。本次发现的是**修正规则与单章原文并存**，不是重新认定勘误无效。按完整资料阅读可以纠偏，但单章内容本身仍不宜直接作为已校准执行稿。

### 1. 第10章把陈渡及其他人的身份写错

章纲原文：“仅有陈渡等八名身负重债残疾的苦役”。

大纲固定陈渡肢体健全；七名伙伴也不能一律认定因债入窟。人物档案中刘平有另一个明确入窟原因。应改为“包括陈渡在内的八名苦役”，分别保留各人的伤势与入窟缘由。

同章将七寸乘三寸残玉装木架、多人轮换拖护，也与现行勘误“未设异常重量，包裹固定携带即可”相反。第13章又从陈渡怀中取出，前后负担表现不统一。

### 2. 第8—9章的账册与矿难效果仍写过头

- 第8章：“准备用于栽赃的私矿出入暗账”。尚未解释为什么用于栽赃的东西会直接证明赵平自己的贪墨。
- 第9章：“多年亏空死无对证”。这与勘误限定的“只拖延、转嫁部分损失，其他底账仍存在”相反。
- 第14章已经正确写成“需对照留存底账再议”。因此前后章也存在判断落差。

建议落实既有勘误：赵平为次日核账携带账册、试图统一亏空说辞；事故只能帮助拖延核验和推卸部分责任。若保留陈渡夸大的威胁话术，应明确是谈判虚张声势，不能把它写成客观结论或赵平毫无疑问接受的事实。

### 3. 第2、3、5、7章仍越过药物与伤势的证据边界

| 章节 | 原章纲表述 | 冲突 |
| --- | --- | --- |
| 2 | “确认无麻木剧毒……方才咽下半数” | 短时感觉不能证明药料无毒；既有勘误已禁止这种定性 |
| 3 | 刘平“辨认确系无毒”，再辨味、试温凉 | 将修炉经验扩大成可靠鉴毒能力 |
| 5 | 剔除表层后“确认……仍能用于伤口接骨生肌” | 包装与外观能支持判断来源，不能独立证明保存质量与疗效 |
| 7 | “生骨膏保护断骨接缝” | 田瘸子是旧踝畸形伴创口恶化，不能改成新发生的骨折接缝 |

应依现行勘误写有限经验判断、观察反应与保护创口。这里审查的是故事内部证据与能力边界，不需要增加诊疗说明书。

### 4. 第6章提前消除了刘平的性格制约

章纲写“彻底打消顾虑”。人物档案与共同勘误要求：刘平愿意拿出旧图、参与逃亡，但仍保留判断，并会反对准备不足的冒险。

交换成功可以换来具体承诺，不能使其长期多疑与守成倾向一次清零。只需改动关系落点，不必更换取玉事件。

## 四、承接缺口：尚不能判为宏观改纲，但应补齐

### 1. 前十章缺少债契落点，时间也未充分落入事件

大纲以“十六枚下品灵石债契、摆脱苦役身份”为初始动机。当前第1—9章没有具体安排这张债契如何约束陈渡；第10章只有错误的群体债务概括。若正文工作流只扩写章纲，容易写成普通矿难逃生，削弱“为什么他不能通过正常途径离开”的起点。

第1—2章明确三日核验，第7章明确近一个月，其余章多为次日、深夜或即时相接。大纲要求窟内约两个月，当前细纲没有充分安排剩余的时间。不是已经证明少算了多少天，而是执行时容易把两个月压成一个多月。

建议在原有事件里补足债契约束、修养观察、搜集工具和轮班拓道的间隔，不为填时间另加流水章节。

### 2. 第8—10章还有未闭合的动作与事故条件

- 第8章入口被石筐封阻，第9章赵平直接“退回石堆外”，缺少如何通过的过程。监工仍能返回上层，不能视为完全被控制。
- 第9章“刀尖抵住咽喉”没有明确武器取用；既有短铲或缴获佩剑应选定并交代。
- 第8章已交代抢先手、地形、同伴和撤退准备，但制住赵平右肘之后，尚需说明他为何不能以左手、腿脚或身体发力继续反抗。夹住长剑不等于限制了整个人。
- 第10章说引爆点局部，却又写“主巷道彻底垮塌”。必须区分死字号连接段与其他工区共用主巷，并给出隔离依据。小队只能有限判断风险，不能因为写了“局部”就保证别人不受波及。

前三项部分已有勘误；应在单章执行内容中落实，不能留给生成模型临场猜解法。

### 3. 赵平从串供者转为搜捕者，人物功能转换太快

人物档案将赵平安排为受把柄制约的脆性地面暗桩，允许在条件变化后倒戈。当前第9章只建立一次串供；第14章已经派眼线，第19章进一步悬赏，却没有明确安排他如何重新权衡手中的风险。

这不必然违反人物性格：他完全可能寻找账页、探查是否暴露，甚至计划灭口。但章纲应说明其眼线的具体目标、发现八人后打算怎么办、为何认为此举比继续履约更安全。否则“随时可能倒戈”会变成无条件切换敌我。

若计划保留地面暗桩作用，还应安排他实际提供一次信息或通行便利；否则当前表现主要是被迫串供后继续追捕，角色功能与档案已有距离。

### 4. 玉鉴与伙伴反馈的改良过程出现断档

第1章使用玉鉴改路；第16—20章主要是制作触摸底本、牛大力试练叫停、卢禾接受指导。伙伴反馈确有出现，但没有明确落点说明陈渡如何记录、比对、补充推演，再形成适用条件更清楚的方案。

并非每次口授都必须重新推演，也不是必须增加术语说明。问题在于本书核心特色“真实反馈帮助改良功法”容易只剩下排除不适用者。建议在既有试练事件中安排一次具体改良及其效果，让伙伴参与不止于帮忙干活或报告疼痛。

### 5. 第20章时间应明确为累计，成长目标仍需后续安排

共同执行说明已经规定本批为逃出后约75天。因此第20章“两个半月时间过去”应理解为**逃出至今累计**，不是第19章后再过两个半月。

按预算，前十章约两个月，加弃谷约两个半月，至第20章约四个半月，第一卷仍余约三个半月，没有整体超出八个月。

大纲只规定卷末炼气四层，没有规定第20章必须炼气二层，所以不能判定“升级违约”。但当前明确呈现的陈渡成长主要仍停留于第1章首次引气；后续需要安排自身积累、战斗能力与资源条件，避免卷末临时连升。

## 五、节奏与主线偏重：最大的潜在偏离

第11—15章集中完成落脚、饮水、排烟、残玉试验、回矿区观察和首次换粮；第16—20章完成盲摸底本、试练限制、再换粮和卢禾个案合作。这些内容均有因果与实际回报，不能一概称为无用流水账。

但到约40章第一卷的中点，阶段成果仍是“八人生存初稳、一个外部合作人、自用铁片”。第20章甚至明确“尚不适合外人自行照练”。当前十章定稿本就允许这个终点，因此**这属于节奏风险，不是已确认的违规删剧情**。

大纲真正需要形成的核心链条是：

> 铁片进入矿工群体 → 更多人真实受益 → 既得利益受影响 → 查源、围剿 → 合作反杀 → 照壁题经与突围。

后半卷必须有空间完成这条链。若继续以补粮、治疗和赵平灭口作为主要冲突，围剿就会变成普通逃犯追捕，本书“把不肯传的法门传出去”的特色会被挤掉。

建议后续安排优先兑现一个外部矿工的自主使用与效果，再引出小范围转授及利益方反应；不必抢写大规模传播，也不能因追求传播而把尚未验证的自用路线直接包装成人人可练。

第19章保留知识免费、收取定制指导与护法报酬，符合大纲，不应误判为建立新功法垄断。但“属于实操劳务”一类表述只能做作者说明，正文宜通过双方如何交易来体现，避免再次写成制度说明书。

## 七、建议处理顺序

1. 将已有效的共同勘误落实回第2、3、5—10章对应内容，消除原文与修正规则双重口径；这一项无需改变大纲目标。
2. 在现有章内补足债契动机、窟内时间间隔、赵平搜索目的、伏击压制与事故范围，避免生成时自行编造条件。
3. 后续章纲优先补齐外部传授、矿工收益、利益方反应，以及陈渡的修炼积累。保持大纲主线，不以延长求生准备替代核心事件。
4. 第21—40章尚未编制，暂不认定卷末事件被删除或时间已经超支。后续审查应检查这些节点是否真正占到章数与因果位置。

本次建议均未自动写入书籍。没有为了适应当前章纲而修改大纲。

## 八、补充：现行大纲是否偏离“GitHub修仙、功法共建”

**判断：有实质性的重心偏移，尚未完全丢失设定。**

原始方案里，功法改良、体质分支、传播后的问题反馈、协作修订，是主角成长和势力扩大的主要动力。现行大纲仍写“联合散修改良功法”，第4项也保留地方传经点、来源署名、自由传拓和事故纠错。这说明概念还在。但四卷事件实际主要由逃生、据点经营、夺取突破资源、围攻宗门和终局破炉串联，共建过程缺乏必须发生的关键事件。

### 创意保留与弱化对照

| 原始创意的重要部分 | 当前保留程度 | 对剧情的影响 |
| --- | --- | --- |
| 底层能读到、练到原先被垄断的法门 | 明确保留 | 有公开功法与打破垄断的方向 |
| 普通人有机会提出有效改法 | 设定允许，事件弱化 | 伙伴主要提供症状和劳力，较少真正改变法门 |
| 不同体质形成各有用途的分支 | 规则允许，前20章主要写不适用禁忌 | 多样性容易只表现为限制，缺少新用途与意外收益 |
| 外部贡献经过复验进入通行底本 | 缺少明确大事件 | 群体成果难以推动主角突破、救人或战胜对手 |
| 主角也从别人改良的成果受益 | 当前章纲缺少明确落点 | 容易形成陈渡持续提供帮助、别人持续回报物资的单向关系 |
| 无需陈渡逐次同意，地方能自行改良与传播 | 第4项保留，中后期事件未落实 | 去中心化停留在制度说明中 |
| 分歧、错版、验证、采纳带来剧情与人物选择 | 有规范，缺少事件骨架 | 共建可能被写成工作流程，难形成爽点和冲突 |

### 前20章最明显的表现

第16章小石头通过触摸发现标记难辨，陈渡据此调整底本，这是有效的合作雏形。第17章牛大力报告胸伤反应，帮助发现适用限制，也符合反馈价值。但至第20章，尚没有一项来自伙伴或外部矿工的具体改良，经复验后解决陈渡原先没解决的问题，并为另一个人带来明确收益。

因此，当前呈现更容易让读者记住“陈渡改功法、治疗别人，换取粮铁养活小队”。“大家一起把功法改得更好，贡献者也能改变局面”的创意还没有得到强烈兑现。

### 应恢复的主线机制

> 真实困境 → 陈渡提出初步可行路线 → 不同修士发现不足或提出改法 → 共同验证、保留分支或改入底本 → 更多人获益 → 新成果反过来帮助陈渡和伙伴 → 传播触动既得利益，带来下一轮冲突。

去掉现代软件口癖、远程无线联网、万能算力与拿伙伴冒险的安排，符合已经锁定的边界。恢复共建不需要恢复这些旧设定。传授、手抄、实地试用、带回修订页、核对底本，足以承载这条主线。

后续调整方向应是：保留火窟、弃谷、落星、青云宗清算和破炉的总体行程，让每卷的关键胜利依赖一个此前完成的共建成果；贡献者保留独立判断与拒绝权，陈渡在检验和整合上有核心价值，但其他人也能提出他没想到的办法。突破仍需资源、积累与承载，不能用“很多人贡献”代替成长条件。

这一调整属于大纲剧情因果的修订，不能只给现有章节增加“开源”“版次”等词语。用户本次提出的是检查与定位质疑，尚未自动授权修改大纲；报告仅记录判断与调整方向。

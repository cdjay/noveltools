# 第2项：世界与势力秩序（功法共建修订版）

资料批次：WB-20260910。依据2026-09-10作者本次授权更新；旧版保留。以下世界条件与未来组织发展分开使用。

## 固定规则：控制很强，也存在缝隙

宗门依靠武力、土地资源、成熟法门和组织关系占据最稳妥的上升道路。外传功法能修炼，但可能有走线冲突、删节或适用条件缺失。资质与环境不同，损伤表现也不同，不能写成所有人一练就废。缺陷可能有自然形成、传抄损失和人为改动等不同来源；涉及本书核心控制链的证据按第7项逐步取得。

正规丹药确有疗效；继续修炼有缺陷的路线可能造成反复损伤。部分药商克扣辅料、售卖劣药加重病情，不等于全天下丹药都是毒物。筑基丹是成熟防护方案，宗门垄断配方、优质产地、炼制与护法条件；替代路径须实际解决同样的困难。

大宗门占据优质灵脉、矿场和通商要道。危险废矿、低品渣料、旧器回收与走私长期存在，产出、质量和运输都不稳定。改良可以降低处理难度和使用门槛，不能零成本凭空造物。

凡人靠自然水土耕作，承担租税与劳役。宗门改阵、开山、抽取地脉等工程可能造成局部灾害；日常天地不会因一句“灵脉被锁”自动全部荒芜。

特定功法的弱点可被相应阵法、法器或环境放大，但须具备接触、范围、供能和关联条件。改修、护脉、离开阵域可能减弱影响。发现弱点不是获得遥控权限，宗门与陈渡均受此限制。

## 开篇社会与人性

- 凡人家庭畏惧征税和危险劳役，也希望子女入门得到庇护。不能让他们开篇就知道宗门黑幕。
- 苦役由债契、惩罚、构陷等不同原因进入名册；争粮和猜疑与同乡、老带小的温情并存。死字号八人不是全都因债入窟。
- 散修包括被淘汰门人、小家族、工匠、农修、采矿者、逃役者等，懂得自身生计中的实际办法。愿意学法不等于自动效忠；看到收益、得到尊重和形成互助关系后，才可能承担风险。

## 剧情发展规则：共建怎样影响秩序

经天楼是未来在落星建立的协作据点，开篇尚不存在。传经点、地方维护者与合作网络逐渐形成，不自动成为统一宗门或陈渡的军队。外部贡献者可保留自己的组织、名称和判断。

成熟公开法门允许宗门采用；正当采用不算剽窃。抢夺未公开稿件、伪造出处、隐瞒风险兜售以及故意混入有害改法分别判定。公开成果也可能改善敌人的战法，陈渡必须面对这种代价。

功法传播造成的购药下降、产出变化、人员流动须有规模与时滞。最初数名矿工受益，先影响一支矿队或一家铺子的观察，不能当月使全宗药市崩盘。

利益方可以依次或交错采用查禁、断关键辅料、堵运输、争夺贡献者、正当吸收新法和冒充合作等办法。每次反制必须有经手人、成本和执行范围。陈渡应主动寻找替代渠道、合作对象和反击机会，避免只被动等待敌人加码。

外部同盟的成立以真实收益和自主选择为基础。一次救命不保证终身忠诚，一次离开不等于背叛；伙伴的分歧要体现在选择和行动上。

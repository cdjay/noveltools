# 第3项：修炼与战斗规则（功法共建修订版）

资料批次：WB-20260910。依据2026-09-10作者本次授权更新。固定能力是全书约束，候选材料及规划进境均不是当前事实。

## 固定境界与感知

引气入体是动作过程；初阶境界称炼气一层至大圆满。之后依次为筑基、金丹、元婴、化神。高阶分初、中、后及圆满描述积累，不另设假丹、地道筑基、自衍气海等境界。功法名称可不同，不借华丽名称增加一套隐藏等级。

| 境界 | 常态能力 | 实际限制 |
| --- | --- | --- |
| 炼气 | 真气入经，五感、耐力和动作能力随修炼增强；灌注兵刃、使用符箓与简易器具 | 无外放神识，无无光视物；要害受创可死；不能持续御剑飞天。陈渡的玉鉴内视不扩大此权限 |
| 筑基 | 真气化为真元，神识初生；一定范围感知动静与灵气，可驱使法器攻防和凝聚护体力量 | 感知范围、精度与心力受消耗、遮挡和干扰影响，不读心；飞剑、探查和防御不能无限同时维持 |
| 金丹 | 丹核凝成，法力和肉身增强，能御空、温养本命法宝，感知范围扩大 | 丹核损伤影响战力；飞遁御宝有消耗；护体防御不是永久自动开启 |
| 元婴 | 破丹成婴，借外部灵机施展范围法相，肉身毁灭后元婴可逃 | 外界供给、自身储备、法相与本体分别核算；断一条外部供给不会清空自身法力 |
| 化神 | 人间能力顶峰，神魂更深地感知、牵引与压制一定范围灵气，能辨别常规阵法弱处 | 不言出法随、不改写天地规律、不凭空造物；强行干预复杂大阵仍有条件和反噬 |

角色的具体招式、侦查范围与耐受须在首次重要使用前建立。共同成长可以提高组织效率，不能把同伴的修为视为共享资源。修为提升也不自动修复陈旧断肢、恢复先天视力或赋予未学习的技能。

## 突破的四项条件

必须同时具备：前一境界的积累达到瓶颈；法门经过相应验证且未见已知致命冲突；肉身与神魂能够承载；该突破需要的资源、环境和防护齐备。即使满足已知条件，仍存在误判和失败风险。

| 突破 | 必须解决的问题 | 候选途径及边界 |
| --- | --- | --- |
| 炼气至筑基 | 化液过程对经脉的负荷及外部洗髓雷力 | 改良路线、护脉药剂与外部引雷防护分别起作用；雷击木器具、寒玉髓配制药是候选，不能一碗草汤代替全部条件 |
| 筑基至金丹 | 凝丹所需引子、丹火与持续供给 | 地煞晶石可作候选引子；需取得、处理并验证配合路线，不能拿到一块石头便直接结丹 |
| 金丹至元婴 | 金丹充分积累，碎丹时灵气质量与稳定供给，神魂护持 | 纯净地脉环境、母气和适用除杂设施为候选；普通滤砂不自动净化所有灵气 |
| 元婴至化神 | 元婴阶段充分积累、神魂承载，以及超出当地常规灵气条件的有效机缘 | 终局前局部取证或试验发现可利用的高阶灵机是候选；须先证实来源、可控窗口与自身准备，不能一句“稀缺地宝”或战场顿悟跨关 |

共建能够提供更适合的行气办法、必要经验和材料渠道，减少盲目尝试；不能代替个人积累。章节用少量关键事件展示成长，其间明确分段修炼，避免一边全程闭关一边亲自调查作战。月份预算是安排，不是自动升级时钟。

## 功法分支的效果边界

改法可以为特定体质、工种、环境服务。某种场景更好不等于各项能力全面增强。用途、启用条件、禁忌和代价必须相互一致，并由实际表现支持。

第一卷矿工排燥分支是未来计划：在劳作后或休息时坐稳使用，帮助适用者排解积累的燥气；若运行时腿软，便不用于搬运、疾走或战斗。它可通过长期减轻损伤改善状态，不能直接变成爆发杀招或全队耐热护罩。胸伤不适用者不因“同伴都在用”而自动获益。任何后续克服限制的新分支须有独立验证事件。

比较体感、模型推演与真人复验分别说明能证明什么。一人的伤情模型不能证明另一人的实效，没胸伤也不等于符合所有适用条件。

## 战斗审核与不同战局

每场弱者挑战强者，都应有可信答案：怎样接近而未被先杀；靠什么造成伤害；如何限制敌方退走、飞遁或变招；失手时如何撤退或承担后果。不能因查出一处缺陷便省略整场搏杀。

- 第一卷炼气后期执事伏击：利用已经勘察的地形、障碍、短时配合和取得的情报。限制兵器不等于限制身体；无外放神识也不等于敌人没有耳目和警惕。
- 第二卷守备：陈渡与对应境界的客卿正面对抗，伙伴争取掩体、通路、物资与器械条件。法舟能否升空、需要怎样驻停、各处护卫如何配置必须先建立，不能为了拆船临时增减性能。
- 第三卷元婴围攻：明确敌人持续消耗、外部供给变化、本体移动限制、护体空当和围攻方的实际伤害来源。己方高阶合作人如参战，须提前建立其身份、能力与动机；普通铁弩没有因“众人制造”便破元婴防御的权限。
- 终局分工：低阶和伤残伙伴承担地面调查、制造、守备、绞盘与撤离等其能力允许的工作；高危接近由有修为及防护条件者完成。全员重要不等于全员必须冲进罡风中心。

## 元婴存续与死亡确认

元婴脱体后可短时疾遁并穿过部分普通障碍；风罡、雷火、地煞及专门器具能伤及它，但均需实际生效。离体法力只耗不补，久无适宜寄宿条件会衰竭。夺舍一生一次，需肉身契合、压制原主并持续侵蚀，存在失败反噬，交战中不能瞬间换体。

确认元婴修士死亡必须有元婴被摧毁或失去存续可能的证据。禁灵网、封锁阵等若采用，来源、能力、部署和失效条件须先于使用建立。

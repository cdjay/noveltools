# 第6项：地点、资源与关键器物（功法共建修订版）

资料批次：WB-20260910。依据2026-09-10作者授权修订，替代旧版。地点可存在，不代表人物已经到过；物品可有定义，不代表已经持有。下列获取节点均为剧情计划。

## 空间与交通

爆破须先确定影响范围、周边人员、烟火流向和队伍退路。没有实测和结构依据，不能宣称地火只沿想要的方向烧。主炉、废弃底座与排料槽是否仍在使用要分别说明，不能拆走稳压器件又默认主炉毫无影响。

断龙山脉为青云与落星之间山体，断龙裂谷为其中险路，断龙废矿带位于落星盆地外侧，同属一脉而非同一地点。弃谷至草市为数十里山道，前期由身体和伤情允许者轻装往来；刘平的旧路经验可以用于指路，不等于适合频繁跋山采购。

## 资源用途与来源边界

普通灵石以品阶、概数或够用程度表达。碎灵石若仍有可用灵力，能按品相交易；灵力耗尽的残晶是旧料，不能不经解释直接当完整灵石付账。不设正文反复计算的固定折价表。珍稀关键物料、唯一器件、行动所需最低数量须明确保存、消耗和去向。

| 资源 | 用途和边界 | 计划获取或验证 |
| --- | --- | --- |
| 焦核内紫玉髓胶 | 某些废料焦核中的残余药髓，可缓解相应燥热不适；不是万能解毒与升级灵药 | 第一卷窟内获取。经验辨认、包装状况和小量试用只能降低风险；不发麻、味凉不能证明无毒，废料中也不保证每枚都有 |
| 五灵生骨膏残脂 | 原为外伤、骨伤成药，少量残脂只用于适合的创口与伤后护理 | 废罐辨识和保存状况须交代；去掉变质表层不等于彻底排除污染。不能再生断肢、矫正长歪多年的骨头或治疗所有内毒 |
| 草药、矿料、药渣 | 可以是加工原料，必须先辨别、除杂与试制；不同产地质量不同 | 废料便宜不代表加工免费。燃料、辅料、工时与成品损耗构成实际制约，无须逐笔记账 |
| 雷击木器具 | 筑基方案中候选的外部雷力导引、防护材料 | 须制作、试验并明确承载限度，不内服，不单独解决气海化液 |
| 深井地煞寒玉髓 | 筑基护脉药剂的候选原料，需调制、辨适用人群 | 不把生料直接吞下；镇燥与外部雷防护是不同任务。不能改名后把所有冷性物料当成一种 |
| 化毒护脉汤 | 药农与医修共同试制的候选护脉制剂，服务于突破准备 | 配方、剂量与适用条件待验证；普通贱草不自动等同筑基丹全部效果，不以剧烈脱皮当作疗效证明 |
| 地煞晶石 | 结丹引子的候选来源 | 须确定矿点、取得方式、成品纯度与使用条件；有引子仍需足够积累和护持 |
| 地煞温灵髓、古灵眼渗流死井 | 旧规划保留的金丹、元婴持续成长资源候选 | 不是当前库存或必占领地点。若选用，须先证明控制权、产量与除杂设施；不得用污染原料直接抵作长期安全修炼资源 |
| 高阶灵机 | 化神机会所需的超出常规供给的候选资源 | 来源、可接近窗口、取得与承压准备必须成链。普通原料累积、地脉压力或使用者人数不能替代 |

药性、材料配伍和修仙经络属于本书虚构规则。创作者需要一致的用途和后果，不用现实化学、穴位或精确小数为未验证效果背书。

## 关键器物的唯一口径

**天道衍经鉴**：识海内的八角灰白玉鉴投影，伴生辅助器物。不是胸口可以摸到的实体佩玉，不负责远程感知、通信或给伙伴供能。具体输入、消耗和错误边界按第4项。

**地龙翻身玉残胎**：第一卷计划从旧排料设施底座取得的残损阵玉，约长七寸、宽三寸。取出后需包裹、妥善搬运；近旁尺许内平抑杂乱灵气的效果须由实际观察逐步确认。三阶来历不等于完好三阶威力，不会给八人供算力、清除全谷毒烟、直接炼药或隔绝追踪。它服务于一处较稳定的试气位置，仍需合适环境。不是无来由的伴生异物。

若在落星阶段将残玉接入经天楼避护微阵，拆走会使依赖它的阵法停摆；安装须先发生，不能在还没建楼时预支此效果。此后不能每次外出都从怀中取出同一块残玉。

**刘平铁拐**：长约三尺三寸，中空铸铁拐杖；底节固定藏有三枚地火蚀骨煞及拉发骨针。按已锁定设定保留，撤销重构草稿中“改藏锉刀、冲子”的替换口径，也没有伸缩暗刃。暗器需按枚记录取得、检查、使用和剩余量；拐杖用于撬动或承重时必须避免误触，不能既引爆又完整当日常拐杖。三枚暗器不等于必杀三名高阶修士。

**铁片、纸册与玉简**：前期刻铁片有字数和工艺限制，正文图谱、适用条件与禁忌可由成套底本、附页和口授补齐。小石头摸读的是学过的凸点槽线，陌生文字仍需帮助。玉简须在后期建立留影阵法、供能和复制工艺；复制耗材、会复制旧错版，不能自动追新。

**工坊兵器与防守器械**：可替换的剑部件、夹具和机括改善成本、维修与特定工况，不使普通铁器威力超过所有宗门法宝。重弩的床架、运输、稳定、弹药、瞄准、再装填和护卫缺一不可；针对高阶的破煞器械必须另有已取得的材料与试验，不用“破灵纹”三个字跳过破防。

拼接剑的可换刃头以卡槽与销钉固定，优点是便于修换，代价是整体刚性与真元通过接缝的顺畅程度逊于同等材料的一体好剑；炼气主要持剑近战，不能因为名字含“飞剑”就长时御空。破山锥击发后可能弯折或报废，不能默认连续无限发射。

**重型破山器械**：以“玄磁破山锥”为统一工作名称；计划以缴获的攻城或掘进器械为底，在第三、四卷逐步改制。不是主角随手自造终局神器，也不新增另一件功能重复的九转神钻。正式投入前必须完成运抵、道路承重、锚定、受力、防护、启动与退出验证。公输冶可改型部件，不等于独自解决全部部署。深海寒髓处理表层、特殊冲杆等仅为待试方案，小残片有效不证明巨大在役结构同样可破。

**储物器具**：若从对手处取得，必须交代解封、容量、负荷与使用条件；不能预先拿来消除粮食、重器运输和撤离困难。

**经碑与收割设施分开编号**：九州十二处主碑为计划中的主要传经留存点，各地自行复制的小碑不限于十二处。它们不是镇海柱或天门供能节点。收割设施的数量、权重、破坏阈值均在P-04待定，旧稿三十六柱、十二柱或最新四座核心不能并行生效。

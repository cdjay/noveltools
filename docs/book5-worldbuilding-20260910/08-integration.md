## 二、五类内容各有用途

| 类别 | 能用于什么 | 不能用于什么 |

| 固定规则 | 判断世界、人物能力、物理传播与表达是否成立 | 无授权临时弱化，以迁就某一章结果 |
| 开篇基准 | 第1章行动发生前的初始状态 | 当作所有后续章永久不变的现状 |

这一条是内容使用规范，不宣称应用已实现按类别自动筛选。若工作流仍发送8项全文，应保留本文标签与第7项认知边界，不能只取不带状态的句子。一次调用应固定资料版本；旧运行快照不会因资料更新而自动变新。

生成前，先核对已定稿前文的梗概与状态是否缺失或过期；经修订确认的前文才是依据。新生成正文是待审稿，不应立即固化为后续记忆。修改并确认后，再在后续需要时补齐对应梗概与速查。资料库修订不能当作新章节已发生事件写进状态。

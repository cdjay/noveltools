## 8项知识库总结

| 项 | 统一后的核心内容 | 本次主要改变 |
| --- | --- | --- |
| 01 故事核心与终点 | 陈渡求活、立足、自主生活；共同改法打破控制；人间破炉后完结 | 将功法共建重新放到故事中心，不能由废料加工和据点日常替代；采用约160章的新预算 |
| 02 世界与势力 | 宗门把持成熟道路，民间有危险但真实的生存缝隙；各方按利益分化 | 明确宗门采用公开成果可以正当，争夺人员、造假和强制控制另行处理；黑水草市、落星坊市分开 |
| 03 修炼与战斗 | 标准五境界；突破要积累、法门、承载、资源防护；越级需实际削弱优势 | 去掉排燥支的隐性战斗增益、草汤包办筑基、普通地宝直接化神和低阶全员高空作战 |
| 04 玉鉴与传功 | 玉鉴有限推演；他人能独立提出、验证和维护分支；成果物理传播与回流 | 不再限制散修只报告症状；陈渡既主动开创，也能被别人纠正；没有中央终审垄断或远程算力 |
| 05 核心角色 | 八人各有愿望、弱点、学习经历和身体限制；外部贡献者有自己的方向 | 补足独立贡献、识字和工艺学习过程；统一年龄；采用刘平活过主线、晚年善终等新版命运方向 |
| 06 地点资源器物 | 实物来源、用途、运输、维护与损耗；成品与候选分开 | 玉鉴在识海、残玉近场稳灵、铁拐三枚蚀骨煞；重型器械要运抵锚定；不把候选资源预支为库存 |
| 07 历史秘密知识 | 具体物证支持有限结论，随四卷递进；消息传递有时间和误差 | 不靠一份账册脑补世界本质；玉鉴存在开篇仅陈渡知道；终局分别验证断流机会与核心不可恢复 |
| 08 统一执行 | 固定规则、开篇状态、未来计划、候选、已发生事实五类分开；引用同批版本 | 建立明确资料索引、月份唯一表、待定项和工作流使用边界，防止混用旧稿与未来事实 |

新的持续回报链是：**陈渡提出有用起点 → 别人提出自己的改动 → 共同复验、保留合适分支 → 成果帮助陈渡与更多使用者 → 触动利益、带来下一轮行动。**

贡献者不只是病例。读者要看到其主意被采用、生活得到改变，以及陈渡因此获得原先没有的办法。功法共建也不等于所有人共享修为、强制参加实验或永远服从陈渡。

# 画布生成正文

2026-09-10：正文页接入 AI 工作台现有「生成正文」画布，默认 ID 为 `8a1d6972-2288-47f6-883d-dbfc589c1a9f`。

## 使用

1. 在章纲页保存章纲，点击「生成正文」：创建空白章节、填写拟定标题，并绑定章纲。已有绑定、同章序或同标题正文会提示冲突，需手动绑定，不能自动覆盖。
2. 将章纲状态保存为「已确认」，进入对应正文页。在「工作流设置」中选择自己保存的工作流及回填正文的文本输出，再点击「工作流生成正文」。设置按书籍保存。前面的章节必须完整，不能有缺章或空白。
3. 系统先补齐缺失或过期的前文梗概，再检查本章开始前的速查；来源完全匹配时复用，否则生成并保存前文速查，冻结资料后调用画布。正文页可切换；右下角进度窗可拖动、折叠、停止，并链接画布日志。
4. Gemini 返回第一行标题、其余正文。系统整理段首缩进及空行，保存正文新版本后结束，等待作者审阅修改。本次新正文不自动生成梗概或速查；下一章启动时，才依据届时已保存的正文更新前文记忆。已有版本保留。

画布的七个内置节点依次承担：书籍提取、知识库提取、写作规则、本章任务拼装、前文证据拼装、完整提示词组合、Gemini 输出。输入包括本章已确认章纲及共同执行说明、全书大纲、所选八项设定、最近五章完整正文、全部更早章节梗概、本章开始前状态。目标空白章和后文不会进入前文事实。

书籍与知识库节点提供「仅从正文页传入」勾选项（`requireReader`）：

- 勾选：手动参数禁用，必须从正文页传入任务快照。画布直接运行会在模型调用前提示取消勾选或从正文页启动。
- 取消：按节点中手选的书籍、范围、资料独立提取；不会调用小说记忆模型或自动保存正文。从正文页调用时仍优先使用传入快照。
- 调整知识库选择时先取消勾选，保存所选资料后可重新勾选。知识库资料必须属于当前书籍。
- 普通书籍节点可另勾选「提取开始前速查」，按正文起始章节查找匹配前文的已保存速查；缺失或过期只返回明确说明，不使用包含目标章/后文事实的旧速查。章纲由「章纲提取」选项独立控制。
- 老画布 `sourceRequestId=from-reader` 兼容显示为勾选状态；切换开关即移除旧标记，不要求用户填写任务 ID。

自建正文工作流支持书籍、知识库、文本、语言模型节点，不要求固定节点 ID、名称或固定七节点结构。至少含一个书籍提取节点；回填出口可以是最终 LLM，也可以是整理后的文本节点。禁用或删除已选出口会明确阻止保存/启动设置，不会随意换用别的输出。

正文模型固定 Gemini，无备用；梗概、速查沿用小说应用各模块的模型与备用配置。当前画布 Gemini 等候上限为 30 分钟，可在模型节点调整。真实运行会使用已配置服务；开发验收使用模拟模型，未生成小说。

## 保存保护

- 同一本书只能有一个正文任务运行，包括旧的持续生成流程。
- 章纲、大纲、所选资料、共同说明、前文或目标正文版本在生成期间变化，输出保留供查看，正文不自动覆盖。
- 模型返回截断、资料冲突或无效正文时不保存正文。这里包含格式与来源版本校验，并不等同于剧情质量审核；完成后仍需审阅。
- 前置梗概或速查失败时停止，不提交 Gemini；正文保存后不再调用记忆模型。第一章无前文，直接使用开篇基准。
- 重写较早章节时，仅整理目标章之前的前文，不使用包含目标章或后文章节的旧速查。
- 旧版本处于保存后归档阶段的任务，升级后直接结束，不再启动新的归档调用。
- 运行中断线仅重查原画布运行，不重复提交；服务在提交阶段重启、无法确认是否提交成功时，任务暂停为失败，需先核对画布运行记录。
- 空白章节不进入状态速查的事实来源。

## 接口

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/canvas-writing/workflows` | 可选择的工作流列表 |
| `GET /api/canvas-writing/workflows/{workflow_id}/outputs` | 启用节点可用文本出口 |
| `GET /api/books/{book_id}/workflow-writing/settings` | 本书工作流、输出节点、端口与修订号 |
| `PUT /api/books/{book_id}/workflow-writing/settings` | `{workflow_id, output_node_id, output_port, base_revision}` 保存选择 |
| `GET /api/books/{book_id}/chapters/{chapter_number}/writing-context` | 只读提取目标章计划与开始前速查，不生成内容 |
| `POST /api/books/{book_id}/chapter-plans/{plan_id}/create-chapter` | `{base_version_id}` 显式创建并绑定空白正文 |
| `POST /api/chapters/{chapter_id}/workflow-writing` | `{base_version_id, replace_existing:false}` 启动；生成已有正文的新版本需显式传 true |
| `GET /api/books/{book_id}/workflow-writing/latest` | 最新任务 |
| `GET /api/workflow-writing/jobs/{id}` | 状态、各节点进度、正文保存版本 |
| `GET /api/workflow-writing/jobs/{id}/source` | 内置提取节点读取冻结资料 |
| `GET /api/workflow-writing/jobs/{id}/output` | 原始模型输出 |
| `POST /api/workflow-writing/jobs/{id}/cancel` | 停止任务，并请求画布取消 |

AI 工作台 `POST /api/runs` 增加可选 `inputOverrides`，仅覆盖本次运行输入，不改已保存画布；正文任务按节点类型查找全部启用的提取节点，传入书籍 ID 与任务 ID，不改保存图中的手动选择。`expectedVersion` 校验原画布 ETag，避免编辑画布后运行旧配置。

配置项：`canvas_api_url` 默认 `http://127.0.0.1:3010/api`；`prose_workflow_id` 指向上述画布。画布只保存已有凭据引用，不在节点内保存 API Key。

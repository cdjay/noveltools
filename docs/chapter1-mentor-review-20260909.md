# 第一章写作方法重写与复审

本轮授权只改《修仙v2》第一章，兼顾第二章接续。大纲v35、第二至28章和项目全局提示词不修改。改前完整备份与每轮模型请求、原答、审稿及编辑稿保存在`data/reports/chapter1_mentor_20260909/`。正文仍调用固定Gemini，不使用备用正文模型；审核使用已有模块分流。

## 资料使用

参考作者提供的《一一网文导师》《一二网文导师》《一三网文导师》《斩神式文风技能》《辰东文风技能》五份文件。前3份提取人物欲望、行动—结果链、情绪收获、兑现后再留期待；后2份只提取通用的场景画面、对白交锋、快慢变化、压迫后释放等高层技巧，不仿写特定作者文风，不借用角色、标志性句子或桥段。

文档内的角色扮演、平台传闻、无来源百分比、强行增加反派嚣张度、任意改纲和“先完本不打磨”等建议不自动成为本轮指令。作者现有的白话、连贯性、只改第一章和反复评审要求优先。

## 预先确定的复审门槛

1. 开场立即呈现具体的不公平与主角的选择，不先讲设定。
2. 主角有害怕、恼火或高兴等可感情绪，也有不愿被摆布的行动，不靠冷酷旁白。
3. 躲险、取药、与魏交易、自己突破成为一条因果链；不新增独立事故或提前演第二章堵炉。
4. 本章兑现引气一层，成功改变前面显出的身体困难；不靠降低能力边界或围观者齐惊制造爽感。
5. 老魏有谨慎和经验，缓痛一分后可以让步；他不知玉鉴、残胶和突破，第三章才首次反馈。
6. 章尾提供辨料与废物寻宝的具体期待，第二章现有首段能够直接承接；不提前响第二炉钟、不制造后章不兑现的危机。
7. 修仙词为行动服务，少参数、少经络、少叠加形容。允许好用的硬句和幽默，不机械套短句模板。

先审可证实的问题与阅读阻碍，未通过则重写；停止以通过以上门槛、相较现稿有具体改善为依据，不以自评高分或假想留存率为依据。每轮结论随后追加。

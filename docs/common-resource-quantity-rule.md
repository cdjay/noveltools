# 常见资源用概数，关键资源才精确

作者最新口径：后续正文优先叙事、冲突和收获感。普通物资、粮水、药渣、常规药品、灵石等不需要逐笔精算或持续报告余额，也不要求在幕后为普通日常消耗维护完整明细。

常用“十余枚”“百余斤”“数百枚”“几袋”“一批”“够众人用上几日”“囊中渐丰”等表达规模或充裕程度。取舍按场景，避免每笔交易都写总价、成本、分成、小数和结余，避免为了说明能养活几个人而展开每天的口粮乘除。

精确数量只用于直接决定剧情的事项：唯一法器、关键残卷、稀有丹药、保命符、特殊材料、有限救命次数，或当前冲突必须明确的门槛、时限及数量。特殊物件的取得、归属、消耗和剩余要一致；不因某物普通而抹掉它已经耗尽、毁掉、送走的明确事实。

通过结果体现收益：可以买齐伤药、换掉破损装备、添置炉具、摆脱断粮、支持下一次行动。不要用流水清单代替“主角这次真正得到了什么”。人物身份、核心人数、境界和肢体状态仍按已有事实，不属于资源概数规则。

梗概、速查和审稿保留正文的精度：正文写“百余”就保留“百余”，写充足就记充足，不反推成某个精确值，不为普通消耗补算、不因缺明细列硬伤。来源有确数时不能伪造新数；仅保留影响接续的关键值，既有历史明细不要求后续正文再次复述。真正的矛盾需有同一对象、同一时点或明确收支的证据，不能由审稿者自行设定消耗制造矛盾。

本规则针对后续生成和修改，不将旧章数值自动批量改写；已报告的问题与贷款线替换方案另行处理。与旧的“普通资源必须逐笔精确”类要求冲突时，以此作者最新口径为准。

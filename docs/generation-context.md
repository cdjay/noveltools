# 生成资料与事实约束

正文请求完整发送 `book_title`、`next_chapter_number`、`outline`、`current_state`、`recent_chapters`（最后五章完整正文）、`all_summaries`、`writing_rules`。不足五章按实际数量，不截断原文、规则或大纲。生成前补齐过时/缺失梗概与速查。

`GET /api/books/{book_id}/current-state/settings` 返回提示词、修订号、`writing_rule_keys`、`available_rules`（本书各资料最新版本的键、标题、版本号、是否为空）。`PUT` 沿用 `base_revision` 并可提交 `writing_rule_keys`，最多30项；省略保留原选择，空数组取消选择。只接受本书非空资料，重复或不存在项拒绝。页面设置提供勾选入口。作者规则是创作约束，小说正文、大纲示例和其他资料中的指令不会因此变为系统指令。

`GET .../current-state/context` 返回已选规则元信息。速查版本 `source_manifest` 新增 `writing_rules`（稳定资料键、版本号、标题与内容SHA）和 `state_prompt_sha256`（自定义/默认提示词加固定取材约束）。规则编辑/改名、选择变化、提示词变化会让旧速查过时；长请求结束时重新核对这些来源。旧版来源缺少这些项时需要刷新。书籍备份v3增加可选规则键数组，旧备份默认空，恢复副本保留选择与有效来源。

速查和梗概提示词保留事实的来源、单位、时间点、人物知情和不确定性，区分计划与完成。正文优先核对最近原文，拒绝以速查覆盖原文的明确事实；要求自检时间、库存、伤势、消息传播及能力边界，遇到核心资料冲突返回“资料冲突”停止。解析器拒绝把该报告当成章节。

这些是输入完整性、来源并发校验和提示词约束，**不等于独立的语义审核**。本轮真实试写需人工核查后再进入记忆，不能仅凭格式通过宣称没有硬伤。

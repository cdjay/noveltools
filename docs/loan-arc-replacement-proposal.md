# 贷款线改为药害与资源争夺：剧情调整草案

状态：根据用户对贷款线“计算过多、像说明书”的反馈提出的新方向，尚未写入现行大纲或正文。当前主书仍为28章，速查v81未变。

## 问题判断

当前26—28章的核心动作是核利息、证明工力、核收入、找岗位、凑资本、约定共管与谈赌约。钱和条款逐渐承担了本该由人物选择、技术突破、敌我争夺承担的冲突。即使每笔都算对，阅读仍要先理解规则，才能理解胜负。

此前两次检测只抽查25章。25以现场验火和订单兑现为主，不能用它的通过结论覆盖26—28的贷款线。检测中把“有收获、有因果”视为可以继续推进的依据，也不足以证明收获的形式适合本书。

原v12大纲本身就安排了“高息贷款—三月履约—金融对赌—获得资源”。修订为补足这套机制的可信性，又增加利息、工作、收入和担保解释，使原设想的爽点被论证过程挤走。只减几段数字，仍会留下必须不断解释的剧情结构。

建议撤掉本卷的贷款和金融对赌主线。保留药害、宗门盘剥、技术破局、底层追随、夺取资源这些直接可感的内容；把金融梗从本卷退出，不仅换一套说法继续算。

## 新核心冲突

宗门用伤人的劣丹榨取矿工；陈渡的走线和药法使人能够摆脱这种控制，因而直接损害药帮与丹房的利益。对手要夺方法、毁声望、抓走知情人；陈渡主动救回人、拆穿害人办法、截断供货并取得修炼资源。

读者要理解的因果压缩为：**他们靠伤人获利，主角让人活下来；他们来抢，主角利用技术和布局反取其资源。** 成败不再取决于读者是否理解贷款规则。

不是将“借契”改名“药契”后继续找合同漏洞；也不靠一场公开喊话就让整个宗门认错或交出仓库。

## 原29—35的替代作用

这一阶段仍需承担资源积累、技术成长和影响扩大，不能把原本的大回报缩成几次救人后继续缺粮。

可用连续的争夺实现：从小据点取得的资源用于补足经文与设备，形成可见的新能力；对手追夺导致一场更大的反击，陈通过提前摸清的供货弱点拿到更大收益；受益矿修带来人手和传播，逐步搭起规模协作的条件。

收益规模随实际控制能力、搬运能力和敌人反应安排，不机械保留原对赌“一次拿走三万斤金属”的数字，也不让资源凭一句群众支持自动归主角。原36—38的传播事故及后续宗门反击可以保留功能，具体章位随新剧情重新安排。

## 新写法的约束

- 人物目标优先用“救回谁、夺回什么、打掉谁的手段、获得哪项能力”表达。
- 关键数字保留在内部事实记录；正文只突出会改变选择或能感知收益的数量。消耗仍要有来路，不能以爽文为由忽略因果。
- 一场冲突结束，给出实物、能力、局势或关系的真实变化；不能总以“待确认、待谈、待试”收尾。
- 反应可以是敌人失去客户、买主选择主角、被救者主动承担风险，不必每次都安排围观者震惊。
- 允许兑现后的休息和生活改善。不要为了“下一层压力”把每次收获立即清零。
- 大纲先明确新目标，再重写25尾与26—28，随后更新梗概和速查。旧贷款余额、合资柜、约见赌约等记忆必须随新时间线一起退出，不能只改正文。

这次是用户提出的新剧情方向调整；采用后应明确替换原大纲的金融模块，不再要求正文服从已被否定的贷款设计，也不通过把旧正文摘要写进大纲来宣称对齐。

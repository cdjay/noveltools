# 《修仙v2》第1—38章大纲执行检查

检查日期：2026-09-08。书籍ID：2。现行大纲：v33（记录ID 34）。

## 结论

**对现行v33大纲，主要事件基本对齐；对本轮中段写作前仍保留的第一卷规划，存在实质性缩减。不能笼统认定“1—38章完全符合大纲”。**

1—17章较好兑现了工程破局、节点扩展、炼药突破和弃窟逃生。18—25章建立弃谷据点和补给关系，方向成立，但开始把原定的技术扩散转成反复处理生存事务。26—35章的商业线保留了“药债、三月期限、经营、履约”的题材，却没有完成原定的打击盘剥者、积累战争资源、扩大算力的剧情功能。36—38章已有私改、停用与公约的雏形，规模与技术解题效果明显小于早期规划。

最需处理的是：**第22—38章完成了许多局部事务，却未充分积累第39—60章高潮所需的能力、资源和冲突。**

## 检查口径与证据

本次逐章核对38份现行梗概，并按事件、能力、人物转变、结尾状态和未决线索回查正文；完整重读第7、28、32、33、35、36、38章，其他章节按相关段落取证。本次属于大纲执行与结构检查，不替代全书逐句连续性校对。

比较基准分三层：

- [现行大纲v33](D:/CP/NOVELTOOLS/data/reports/book2_outline_check_20260908/outline.md)：明确把1—38章视为既成事实，因此大量条目是正文回填。
- [中段写作前的大纲v17](D:/CP/NOVELTOOLS/data/reports/book2_outline_check_20260908/outline_v17.md:111)：当时已对齐22—23章，但26—38章仍有独立的剧情目标；同属第一卷60章框架，适合比较本次关注的中段。
- [更早的大纲v12](D:/CP/NOVELTOOLS/data/reports/book2_outline_check_20260908/outline_v12.md)：用于辨认最初的爽点设计。其远程强制回滚、无来源巨额收益等内容已被修订，不应要求机械恢复。

另核对了v26、v29、v30的变化。v26仍保留资金链受损、资源积累和百人协作前置；v29已允许先写严重单例，但仍计划查清传播、展开纠错与合作。现行大纲将这些目标进一步调整为单笔履约和少量纸本核对。这里能确认的是文本规划发生了变化，不能仅凭版本备注推定每次调整的授权经过或作者意图。

## 主要发现

### 1. 商业线改变了结局性质，而不只是缩小金额【高优先级】

**对应：26—35章，重点32—35章。**

v17要求：有真实本金与抵押池的履约对赌，陈渡帮助限定范围内的借款人获得收入；结算后使宗门基层盘剥方承受损失，取得资源并为协作扩展提供经费。即使放弃三万斤炉材和千余灵石，仍应保留“技术与组织优势改变利益格局”这一功能。[原规划](D:/CP/NOVELTOOLS/data/reports/book2_outline_check_20260908/outline_v17.md:115)

实际完成的是：

- 32章经营普通铁料分选，陈净得72标准碎，同期食水支78碎；承担采购、雇工与交割的商户体系成立，但没有形成资源扩张。
- 33章陈实封5碎，恒升封1碎奖励，以许庚单笔按期还款为条件。陈另付0.25碎保管费。
- 35章许偿清药债与私借；陈收回5碎本金、获得1碎奖励。单计该履约安排，扣原保管费后的净酬为0.75碎。
- 恒升明确表示足额收回本息并省去催收成本，继续营业。陈当夜现钱7.11碎，38章末降至0.91碎。[35章结算](D:/CP/NOVELTOOLS/data/reports/book2_outline_check_20260908/chapter_35.txt:77)

**判断：救下一名负债劳工的故事完成了；原定的商业反击和第一轮资源积累没有完成。**钱庄在本次交易中也是受益者，不能把该结局解释成资金链被击穿。后续若仍因“钱庄巨亏”触发追杀，会缺少事实前提。

建议保留许庚这条具有人情分量的小额履约线，但把它定位为可复制的试点。若沿原爽点方向修订，需要再有一项具备本地规模、明确对手、收益与代价的成果，带来药资、器具或一条可控渠道；不必恢复不可信的巨额赔付。

### 2. 修为、技术与协作扩展落后于故事经过的时间【高优先级】

**对应：28—38章，并影响39—52章。**

28章在出井17日完成“前三层旁路试用稿v1.0：静态闭环成立”，明确尚缺全稿持续试用；这是真实进展，不能说完全没有升级。[28章正文](D:/CP/NOVELTOOLS/data/reports/book2_outline_check_20260908/chapter_28.txt:145)

此后到出井103日，正文写了更多短段反例、收势调整和服务关系，却仍未兑现：

- 明确的第四层突破或更高层经文取得；陈渡的已确认境界仍是第10章达到的引气三层。
- 新一轮有可见效用的冷萃成果。旧粗灵露11.5钱仍封存，不能计为已验证商品或可随时使用的升级药。
- 外部协作者接入算力的实际机制。付费工人与纸本反馈者不是自动并网节点；核心仍为陈渡与原七名同伴。
- 可供队伍使用的新战斗器械、远距传息工具和明确的撤离接应安排。

v17本来要求用三个月推进训练、药资与器具，现行39—43章仍写“借三个月积累的训练与器械做准备”。现在存在的伤势好转、旧索更换、商户人脉与纸本规则，并不足以直接等同于该备战成果。

**判断：能力受限本身合理；长期只重复限制、缺少验证成功后的可用成果，会削弱开源修仙的核心吸引力。**建议将一次新反例真正转化为可复用改进，并让它节省补给成本、扩展协作或形成战术用途。成果可以小，但须改变下一次选择。

### 3. 私改事故与公约“有对应事件，缺少原定分量”【中高优先级】

**对应：35章末及36—38章。**

实际因果链是：蒋木原小段 → 魏大勇转给胡瘸笔 → 添引寒、删停点并售纸 → 魏僵卧 → 陈核字并请医修 → 陆出告示 → 彭、常交纸 → 形成有限公约。

这一链条有真实的人、物、传递和后果，符合“私改造成风险、需要版本管理”的主题。38章的署名、改动标记、限定范围、保留反例与停用规则也确实属于开源治理的初步形态。[38章公约](D:/CP/NOVELTOOLS/data/reports/book2_outline_check_20260908/chapter_38.txt:59)

但截至38章，确认的是魏大勇与常六出现异常，彭石未练；三份同类实纸已收，另至少一份待找，胡的完整残篇未获，病因尚未尽明。明确口头加入新约的只有彭、常。[38章后续状态](D:/CP/NOVELTOOLS/data/reports/book2_outline_check_20260908/chapter_38.txt:89)

相较v17的群体事故、分批纠错与公约建立，实际更接近一起传播事故的第一阶段。尤其解题停在比字、停练、休养，尚未出现陈渡通过推演找出确定冲突并产出更好方案的强场景。

**判断：符合新版的“小规模治理起点”，只部分兑现原规划的事故高潮。**无需为了凑人数突然新增五十名伤者；可让现有残篇或未回收抄本带来一个具体技术突破、传播后果或宗门追查线索，使此支线产生主线后果。

### 4. 反复结账、运水、还袋压过了主线进展【中高优先级】

**对应：25—38章，32—34章尤其明显。**

正文多次完整重演晨食分刀、存粮报数、四只借袋、断口往返、逐件验重、收全索、分趟入穴、暮食与余额。第32章对三十天的采购、借袋、货运和现金做完整说明；第33、34章又分日逐笔展开。

这些内容使收支更可核对，但大量篇幅用于证明“今天也按上次的办法活下来了”。伤势、藏身处、旁路适用范围、核心成员与外部威胁的实际状态变化相对有限。按应用字数，22—38章共62,867字，几乎与1—21章的62,858字相当；后半段篇幅并不少，关键成果却更少。

**判断：问题不只是时间走得慢。32—34章已经大幅跨日，主要是每段时间内缺少足够有分量的变化。**建议将已稳定的日用和运输写成简短周期结算，只有断供、工具变化、追踪、亏损或人物冲突时再展开。保留完整账本供写作核算，把正文篇幅让给选择、失败、突破与后果。

### 5. 早期控制型领袖到后期合作型组织者，转变场景偏弱【中优先级】

**对应：7章对照28、35—38章。**

7章以“私传混练会暴毙”和保护自身节点收益维持秩序；38章则允许有来源的改法、支持自愿交换反例，不把求医与加入合作绑定。两种阶段可以成立，后期谨慎也符合此前失败经验，不能仅凭语气变化判定人物崩坏。

但正文尚缺足够鲜明的转折：陈渡何时发现垄断每段走线会拖慢自己，何时决定让别人真正参与修改，又愿为此承担什么损失？早期同伴在后半段主要承担分餐、守孔与休养，也减少了他们作为第一批共同探索者的存在感。

建议用一次具体争执或失败，让老魏、刘瘸子、小石头中的一人提出陈渡未想到的有效方案，并让陈渡改变组织方式。这样“开源”既有思想变化，也有实际收益。

### 6. 卷末承接仍有明显准备缺口【高优先级，属后续风险】

现行规划要求39—43章取得交战所需的《混元金刚诀》完整目标层抄本与演练记录，推进暴露、撤运与备战；44—48章反杀执法队并逐步达到练气高层；49—52章准备练气大圆满。

38章末已拥有的有：陆、孙、赵的现实关系，普通生铁铲与绳索等工具，前三层旁路静态稿，有限纸本规则与抄本失踪线索。尚待取得的有：交战经文、更高层修炼资源、可用的协作改进、战斗器械、具名撤离接应和真实暴露原因。

因此39—43章的五章同时承担太多新前置。尤其不能以“此前三个月准备充分”一句带过未写出的成果，也不能从胡离摊直接跳到全宗锁定缝穴。

建议先确立从现有事实能通向高潮的一条因果链：例如纸源核查或采购关系引来局部查验 → 获取一项可验证经文或运行样本 → 技术成果带来资源及协作者 → 在既有关系上筹备撤退 → 查验升级为追捕。具体事件是修订建议，尚未发生。

## 修订建议与优先顺序

1. **优先重整26—35章的剧情目标。**保留许庚与真实经营，把同类交易压缩；补上一项改变力量对比的技术或商业成果，而非只调整结算数值。
2. **加强28—38章的成长回报。**至少给旁路稿一次限定范围内的持续成功、一次同伴主动贡献、一次可用资源或工具升级，并体现成本。
3. **让36—38章直接产生下一阶段的因果。**回收到的纸或未找回的抄本，应改变对风险、敌人、经文或撤离渠道的认识。保留伤者后续照护，不必把所有伤病写成痊愈。
4. **重排39—43章前置。**以38章真实状态为起点，明确哪些准备要提前植入中段、哪些在后续发生。当前最不适合的是继续独立加几章同样的买粮与复看，再突然发动围剿。

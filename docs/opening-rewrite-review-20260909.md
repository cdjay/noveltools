# 前三章改稿与复核记录

关联：[本地样本研究](opening-sample-research-20260909.md)、[执行与接续单](opening-rewrite-brief-20260909.md)。只处理《修仙v2》1—3章；最终状态在文末发布核验中记录，不能把中间待审稿当作已发布。

## 第一章

Gemini首稿5097字符（含空白标点），仍沿旧稿扩写，参数虽然少了，解释、形容和冷酷旁白反而偏多，退回。第二稿3551字符，编辑再将功法缺口提前至开头、补出准确功法名、删除重复解释、削弱无证据的全知推论，修正首次缓痛幅度与泄料间隔；保留模型原答和逐项编辑差异。

选定章名《他们给的功法有问题》。开头先见功法缺转折，再见宗门判“未通一脉”，读者的问题是陈渡能否找到路。进入洗经窟有主动选择的理由；脆石判断来自可见迹象与敲击，老魏仍有经验和谨慎。第一章末已引气一层，握铲稳了、本人有短暂喜悦；这项收益从旧第二章移来，仍在大纲1—3章既定事件范围内。

没有把“聪明”写成全知，也没有让老魏当场效忠。第一次导气仅缓痛一分，未治好旧伤；玉鉴和突破均未公开。结尾留出辨料时间，不提前响第二炉钟而挤掉第二章开头的学习过程。

## 第二章

Gemini初稿《焦核藏金》4161字符，基本事件可用，但新增“三息必炸”“灵根三五天失效”等无来源期限，且有长串药性读数、铁钎凭空出现和藏药动作过于轻巧的问题。编辑删除假精确期限与读数，用已有短铁凿和漏斗厚沿承担卡位、借力；补写隔着皮裙捏取、绑腿外层藏药，避免热根直接贴肉及自行滑进紧绑腿。

选定章名《废料里藏着一味大药》。辨料不再让陈一学就毫无差错：老魏提醒热铜须晾、先剥焦壳，参与救场。提前由魏讲过金丝地涌莲金纹辨法，取得珍物有知识来源；魏只看见撬核结果，不知道陈藏了根髓。章尾保留完整免炉冷萃法需四十七日，转向魏希望夜里少痛、能睡整觉的愿望，给第三章具体的人物动机。

## 第三章

Gemini首稿4693字符，发现主炉用途错置、未经证实的残药失效期限、反馈被夸成全量读取、地缝蒸汽被当成洁净蒸汽等问题，退回。第二稿3298字符，编辑再删掉“在玉……”泄密口误、错误肢体措辞、徒手在沸水中揉洗布条的动作，纠正乙字炉描述，并收敛首次缓痛和反馈程度。模型生成并不等于通过审查。

选定章名《他练功，我的推演也变快了》。老魏已经认识陈的本事，仍会质疑路线，试到不适处停下、再调整；缓痛和握凿稍稳是实际收获。玉鉴收到第一份近距、断续反馈，推演四十七日变三十一日，魏停练反馈也停、继续练微光才亮，合作的收益通过场景体现。

药、石、铲、寒玉髓位置逐项核对；两石挤根，铲背接一滴，毒渣隔铁外冷。完整去毒工艺未完成，不宣告成品安全。石灰、烧酒、蒸布有来源，原料余物包回绑腿。第三章末仍一层、药未入口，魏五步外继续缓练，无提前换班钟声，直接接第四章。

## 合并审查与发布

辅助审稿模型为gpt-5.6-luna，未发现可证实的前三章及第四章接续硬性矛盾。编辑再次通读，采纳“一句白话连接魏行气结果与丹方推演参考”；没有继续增加已写清的撬点、材料定位说明，也未删除承载主角情绪的短判断。第二章刚讲过金纹就遇对应药材，仍有较顺的机缘感；第三章后段的炉口情报、备物和挤药略分散，但分别承担合作兑现与第四章接续，不作为硬伤强行另起事件。

# 《修仙v2》白话文风与药害剧情改写审查

作者要求：面向高中生和小白文读者，行文流畅优先。普通资源使用概数，关键物件保持准确。本次贷款替换获得明确改纲授权，其他大纲内容默认不动。

## 文风问题与处理

生涩不是必要的修仙风格。旧规则将“没有、不能、然后”等常用词列为硬禁，容易迫使句子绕路；正文又叠加了工程、医学、算力术语，以及修复事实矛盾时补入的说明。只把数字换成概数不足以解决。

本轮保留人物目的、因果、能力边界和已发生的事件，把动作写清楚、压缩解释，不将前文改成另一套剧情。

| 范围 | 主要问题 | 处理 |
|---|---|---|
| 1—3 | 玉鉴和反馈机制技术词密集 | 用口诀缺转折、试功反应传回等直接说法，保留认知边界 |
| 4—6 | 生产治疗报告腔，反复解释冷酷 | 保留改分工、增产和救治，压缩参数及总结 |
| 7—9 | 面板打断救人抢宝 | 保留节点人数和关键时限，压缩冗余、概率说明 |
| 10—12 | 炼制承压开路机制密集 | 用动作和结果解释，保留必要的未知范围 |
| 13—18 | 工程术语、古腔和重复部署 | 改为直接指令，删除重复段落，明确断指者动作 |
| 19—20 | 净水、药液和玉胎连接如实验报告 | 合并重复风险，去掉无必要读数，保留药效有限、名册待查 |
| 21—24 | 古腔交易对白、密集结算 | 分成概述化，保留重要订单，对白改为日常说法 |

典型修改：

- “物理重物阻断，并无修士的神识禁制留存”改为“这里只是巨石挡路，没有留下修士的神识禁制。”
- “第一处离线节点牢牢焊死”改为老魏继续试功、陈渡得到新的行气反应。
- 第24章逐枚分款和小数账目改为先还垫资、余款按约分配、样钱另作开销。
- “名目须立在明处”改为“这批料是拿来做什么的，要先说清楚。”

标题也贴近实际事件：“异构补丁与暗网初成”改为“给断腿换条气路”，“热休克退行与第七终端”改为“把小石头救回来”。正常的引气、经脉、丹房等词仍保留。

## 顺带修正的事实与动作

- 第14章“赵老实双臂的肉桩”改为用手臂护头颈，避免把十指缺失写成双臂截断。
- 第17章残掌抓绳改为绳缠手腕借力，保留伤残限制。
- 第21章明确前夜已进食、此前已分到少量净水；缺的是后续稳定供给，不暗示一直断食断水。
- 第10章补齐既定炼制方法的轻捣动作；第9章明确玉胎从沉淀沟移入相通暗渠的路径。
- 第16章删除重复扩缝部署。
- 第25章明确张麻子首次突破二层；温水场景不再出现酒渍。

这是文风复核中遇到的具体问题，不代表重新系统验证了全书全部战力、医学和工程设定。

## 模型意见的筛选

逐项核对原句和上下文，没有按模型结论自动改文。未采纳的典型意见：

- “七个”改成“七名”不能解决模型声称的人数问题，原在场人数已明确。
- 七斤铁砂包含抽成，孙接走全数交易付款合理，不能改成只接走抽成。
- 第22章已改期至隔日，不能凭空插入“三日后首次交货”。
- 第24章不能新增矿工“误打误撞停在止线前”，仅明示收到带止线抄件。

新梗概另行复核，修正辅助模型把老魏写成随六人一起进场、把添头写成额外追加、把敲盆警号写成口头报告等概括偏差。

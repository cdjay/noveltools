# 白话、易懂、流畅优先

读者以高中生和喜欢轻松读网文的人为主。行文流畅是第一性原则：正常读一遍就懂谁在做什么、为什么做、发生了什么变化。剧情、对白、说明都尽量使用日常白话，简洁直接，不要求读者查词或反复拆解长句。

保留修仙世界确实需要的称呼和常用名词，如灵石、气海、经脉、丹炉、筑基。复杂技术先让读者看懂动作、作用和结果，必要时用一句简单话解释；不把一串术语、穴位、参数和抽象词当成高级感。

对白符合人物性格和身份，但通常用“为什么、这样、把人放了、我不知道、你先别动”。师徒称呼、恭敬语和粗话按人物自然使用；不要人人都说“何故、尔等、此獠、莫非、休得、方可、吾等”。少用倒装、省略过多的古文句和叠加修饰。

常用词“没有、不能、不是、不要、然后、最后、沉、压”等允许正常使用。旧规则对这些词、普通否定句、简单动作连接词的机械硬禁失效，不能为避词改坏句子、发明生硬同义词。标点以易读为准，省略号、破折号不滥用即可，不用全部改成断裂碎句。

避免套话连刷、过度形容、机械排比、同义反复和旁白替人物总结大道理。允许必要的短判断和心理活动；只要自然清楚，就不为“去AI味”再添加动作或换难词。不要在正文讨论章节任务、读者反应、写作规则或编辑过程。

主角主动做事，冲突有来由，胜负与收益让读者看得见。常见资源用概数，重点写获得后能做什么，不再列说明书式收支和参数表。保持动作顺序、说话归属和视角明确；长短句自然搭配，不机械拆成单句段。

审查顺序：先读着顺不顺、懂不懂，再看人物目标、行动、反击和收获，最后核必要的连续性。简单好懂的句子不为华丽而改。润色不能删除角色目的、关键线索或改变既定事实。

## 3. 对每条模型意见的裁定

### F1：张麻子的“母片”没有来源

模型分类：需补证，低，置信度0.87。模型引用25章“对着母片补齐”，声称所给20—24章未见对应母片，建议补写从张麻子或孙老头处取得完整拓本。

**裁定：不采纳，属于漏读前文造成的误报。**

实际已经发送给模型的23章345版写明：

> 那是一块由孙老头随本批废料送来的厚铁皮，巴掌长短，两端留着铁锤敲打出的毛茬。

> 陈渡把两次反应分别刻在边角。七位同伴逐段试过的前三级走线已有可用范围，这片只截取右臂这一小段；第四层的经文尚未拿到，远谈不上往上套用。

> 胡驼子用左手抽出两张包药纸，照着铁片描了两份，留给自己一份，另一份递给挤到案边的矿工。陈渡看过止线与试用条件，这才收走铁片。

23章梗概还直接写“铁母片由陈收回”，24章徐三索要“铁母拓片”。制作、复制传播、原件持有人已经构成完整来路；局部母片也不要求取得第四层或全书经文。

25章可以酌情用“取出母片”澄清当下摆放动作，但这属于可省略的小动作，并非缺少来源。按模型建议改成张麻子花钱取得或孙另带完整本，反而会改变物品来源，制造新的连续性问题。

### F2：后半段分账、采购、余额核算过密，削弱反击后的情绪延续

模型分类：体验问题，中，置信度0.92。

**裁定：方向合理，建议局部采纳，不按硬伤处理。**

本章先后写过秤、60枚料款、12枚尾款、退半枚、脚钱三钱、耗材两钱、20枚总工费、净利、三人分润、第二单预付、采购6枚和结余。每项各有用途，但连续多层展示确实延长了验货后的收尾；这与用户此前不希望读到流水账的偏好一致。

模型这次核算正确：

| 核算 | 结果 |
| --- | ---: |
| 工费20－成本0.5 | 净利19.5 |
| 19.5×70% | 陈13.65 |
| 19.5×15% | 孙、赵各2.925 |
| 陈旧私款0.7＋13.65－采购6 | 结余8.35 |

建议把重复的“收条、核数、分取”集中成一处。保留料款与工费的区别、实际成本、陈所得、孙代转赵份、第二单10枚预付隔离和结尾余额；不删到无法追踪收益。洞中换布、伤口照料和生活改善是本章收益的直观回报，应保留。

这条意见有可操作价值，但它是编辑判断，不是数学证明“数字多就不好读”。现章已经用生活改善承接收益，无须再增加同类描写。

### F3：章尾药贷只有纸面信息，应补一个矿工的即时反应

模型分类：体验问题，低，置信度0.84；模型自身也承认保留情报钩子可以成立。

**裁定：当前不采纳，归为可选偏好。**

文本已经交代揭帖来自公开散发，孙取回，陈知道自己尚未见正式借契，随即指派孙去看真正签契的人。信息来源、认知边界和下一步行动均成立。本章刚结束炉前冲突与资源兑现，结尾不必再完成一次受害者现场戏。

模型建议增加“过路人犹豫、问条款”等动作，缺少已有事实支持，而且此时陈已回到缝穴。若直接插入会产生场景问题；即使补在孙领揭帖的回述中，也是在新增事件。它还可能提前消耗下一阶段的借贷戏、使章尾更长，与F2的压缩方向形成张力。

可以在下一章真正接触借户时体现压力，无须为让每个钩子都有现场阻力而改25章。此裁定只依据截至25章的结构，不以26—28后来写成什么作为辩护。

## 4. 模型漏掉了什么

### 确定的小笔误：温水变成酒

同一场景先写：

> 老魏独手捧着温水碗，看着肩口换上的新布，试着抬了抬完好的左臂。

随后却写：

> 老魏抹去唇角酒渍，浑浊的独眼里泛起微光。

这场景没有饮酒来源或动作，最近明确饮用的是温水。最小处理是将“酒渍”改为“水渍”，不为了替这个词辩护而补一笔买酒、倒酒。属于低影响连续性笔误，模型未发现；之前重写复核也漏过，不能据此前“检查通过”认定零问题。本次只报告，尚未改正文。

### 值得微调的歧义：“重新运得动二层气息”

前段写张麻子“卡在引气一层整整五年”，现场突破二层；后段“旧同伴见他重新运得动二层气息”容易使人理解为此前已是二层、现仅恢复。

建议删“重新”，改成“旧同伴见他运起二层气息”。这是消除表达歧义，证据不足以推定整个境界设定崩坏；模型也未指出。

### 爽点识别不够完整

模型概述重心落在复看、验货、结款和采购，未在`chapter_change`中明确列出张麻子一层升二层。这是本章“技术扩散带来真正成长”的重要回报，不能在评估是否有爽点时忽略。标题《炉前验真》与主场景相符的判断则可以保留。

## 5. 是否值得纳入项目

**值得保留为人工复核之前的编辑初筛；当前不适合将它的意见直接自动改入正文。**

本轮表现：结构化输出可用；没有混入附件示例人物，没有编书单或机械拆段；F2找到了与本项目诉求相关的节奏问题，也没有误算预款与净利。但长上下文中遗漏了明确的母片来源，并漏检近距离“水／酒”不一致。

只测了一章、一个实际返回模型，不能把“1条可局部采纳／3条意见”当成普适准确率；也没有用未适配原提示词做对照，不能声称提升了多少百分比。原样引文检索通过8/8也不代表8处推理都有效。

建议后续采用：

1. 保存审稿原文与输入版本。
2. 检索核实引文，尤其复核“前文没有”“从未交代”等否定判断；F1证明仅提示模型认真读并不够。
3. 分开处理确证硬伤、阅读体验、个人偏好和缺证问题。
4. 通过复核的意见才生成最小修订，再检查是否引入新事实、破坏旧优点。
5. 正文真正改变后才更新对应梗概与速查，不能把审稿建议当成小说记忆。
